# A2A K3S deployment (L1 Guardrail + a2aproxy + testagent)

This directory provides the P2-2 A2A K3S LAN verification checklist. **Does not depend on local Docker**: after static cross-compilation, produce a Docker-save tar, then import it into K3S containerd via a temporary privileged Pod.

> Applicable boundary: LAN pre-production verification. The production entry should be changed to ClusterIP + Higress, the registration snapshot should be generated by the control plane, audit should land on WORM, and the Guardrail production tier should connect L2/ML (this directory is L1 rules only).

## 1. Components

| File | Content |
|---|---|
| `guardrail.yaml` | `a2a-guardrail` Deployment + ClusterIP; loads in-image `/app/policy` |
| `testagent.yaml` | `a2a-testagent` Deployment + ClusterIP; `hello_world` test Agent |
| `a2aproxy.yaml` | `a2aproxy` Deployment + NodePort `30086`; static snapshot, signed ACL, static bearer, JSONL audit, content-safety wiring |
| `kustomization.yaml` | Unified namespace `otpmask` |

Prerequisite resources (created by deployment commands, not put into Git):

- ConfigMap `a2a-snapshot`: `snapshot.json`.
- Secret `a2a-proxy-secrets`: `acl.json`, `acl-key`, `auth-tokens`, `guardrail-token`.
- Images: `docker.io/security-ai-gateway/a2aproxy:lan-20261021`, `a2a-guardrail:lan-20261021`, `a2a-testagent:lan-20261021`.

## 2. Build static binaries and image tars

Requires Go 1.26 (the system Go 1.20 does not satisfy `go 1.26.0`). Example:

```powershell
$env:GOTOOLCHAIN = "local"
$env:GOOS = "linux"
$env:GOARCH = "amd64"
$env:CGO_ENABLED = "0"
New-Item -ItemType Directory -Force .tools/a2a-deploy | Out-Null

go build -trimpath -ldflags="-s -w" -o .tools/a2a-deploy/a2aproxy ./gateway/a2aproxy/cmd
go build -trimpath -ldflags="-s -w" -o .tools/a2a-deploy/a2aguardrail ./gateway/a2aguardrail/cmd/a2aguardrail
go build -trimpath -ldflags="-s -w" -o .tools/a2a-deploy/a2a-testagent ./gateway/a2a/testagent/cmd
```

This LAN verification uses a one-off `mkimage` to produce the Docker-save tar (scratch static image). The production build prefers each directory's `Dockerfile`:

```text
gateway/a2aproxy/Dockerfile
gateway/a2aguardrail/Dockerfile
gateway/a2a/testagent/Dockerfile
```

The Dockerfile path requires Docker/BuildKit; when there is no Docker locally, use the static-binary import flow above.

## 3. Import into K3S containerd (no Docker)

K3S's `kubectl` cannot import images directly. Use a temporary privileged Pod mounting the host root directory, invoking the node's `k3s ctr`:

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: a2a-image-loader
  namespace: kube-system
spec:
  restartPolicy: Never
  hostPID: true
  containers:
    - name: loader
      image: busybox:1.36
      command: ["sh", "-c", "sleep 600"]
      securityContext:
        privileged: true
      volumeMounts:
        - name: host
          mountPath: /host
  volumes:
    - name: host
      hostPath:
        path: /
```

```powershell
$kc = ".tools/k3s-kubeconfig-73.yaml"
kubectl --kubeconfig $kc apply -f loader-pod.yaml
kubectl --kubeconfig $kc -n kube-system wait --for=condition=Ready pod/a2a-image-loader --timeout=90s

foreach ($f in "a2aproxy","a2a-guardrail","a2a-testagent") {
  kubectl --kubeconfig $kc -n kube-system cp ".tools/a2a-deploy/$f.tar" "a2a-image-loader:/host/tmp/$f.tar"
  kubectl --kubeconfig $kc -n kube-system exec a2a-image-loader -- `
    chroot /host /usr/local/bin/k3s ctr `
      --address /run/k3s/containerd/containerd.sock `
      --namespace k8s.io images import "/tmp/$f.tar"
}

kubectl --kubeconfig $kc -n kube-system delete pod a2a-image-loader
```

The version of `/usr/local/bin/k3s ctr` should match the cluster; this cluster is `v2.3.4-k3s1.36`.

## 4. Generate deployment fixtures

The fixtures for this LAN verification (signed ACL, random bearer, testagent static snapshot) are in `.tools/a2a-deploy/`, which is already ignored by `.gitignore`:

```text
acl.json

auth-tokens.txt
```

Production environments should not use one-off fixtures: ACL signed and rotated by the control plane, bearer issued by secret management, snapshot generated by the registry.

## 5. Create ConfigMap / Secret

Create resources first, then apply workloads, to avoid Pods briefly hitting `CreateContainerConfigError`.

```powershell
$kc = ".tools/k3s-kubeconfig-73.yaml"
$key    = (Get-Content .tools/a2a-deploy/acl-key.txt -Raw).Trim()
$tokens = (Get-Content .tools/a2a-deploy/auth-tokens.txt -Raw).Trim()
$gtoken = (Get-Content .tools/a2a-deploy/guardrail-token.txt -Raw).Trim()

kubectl --kubeconfig $kc -n otpmask create configmap a2a-snapshot `
  --from-file=snapshot.json=.tools/a2a-deploy/snapshot.json

kubectl --kubeconfig $kc -n otpmask create secret generic a2a-proxy-secrets `
  --from-file=acl.json=.tools/a2a-deploy/acl.json `
  --from-literal=acl-key=$key `
  --from-literal=auth-tokens=$tokens `
  --from-literal=guardrail-token=$gtoken
```

Before re-running, delete the old resources first, or follow the `kubectl create` with a `kubectl apply -f -` YAML flow. `a2aproxy` mounts the Secret read-only; `guardrail-token` and the Guardrail's `GUARDRAIL_AUTH_TOKEN` must match.

## 6. Deploy and probe

```powershell
$kc = ".tools/k3s-kubeconfig-73.yaml"
kubectl --kubeconfig $kc apply -k deploy/k8s/a2a
kubectl --kubeconfig $kc -n otpmask rollout status deployment/a2a-guardrail --timeout=120s
kubectl --kubeconfig $kc -n otpmask rollout status deployment/a2a-testagent --timeout=120s
kubectl --kubeconfig $kc -n otpmask rollout status deployment/a2aproxy --timeout=120s
kubectl --kubeconfig $kc -n otpmask get pods -l app.kubernetes.io/part-of=a2a -o wide
```

Expected:

- `a2aproxy`: `/readyz` returns `ready`; logs show snapshot loaded, governance wired, content-safety wired.
- `a2a-guardrail`: `/readyz` 200; startup log contains rule count (this policy is 10,068 total / 1,466 active).
- `a2a-testagent`: TCP 9001 ready.

## 7. End-to-end check

```powershell
$base  = "http://192.168.31.73:30086"
$token = (Get-Content .tools/a2a-deploy/auth-token.txt -Raw).Trim()

curl.exe -sS "$base/readyz"
curl.exe -sS "$base/a2a/tenant-a/testagent/.well-known/agent-card.json"
```

The `SendMessage` request must carry:

```text
Authorization: Bearer <token>
A2A-Version: 1.0
X-GA-A2A-Skill: hello_world
Content-Type: application/json
```

Request body example:

```json
{"jsonrpc":"2.0","id":1,"method":"SendMessage","params":{"message":{"messageId":"m1","role":"ROLE_USER","parts":[{"kind":"text","text":"hello"}]}}}
```

Verification points:

1. Plain text → `result.task.status.state=TASK_STATE_COMPLETED`.
2. Hits L1 block category → `-32010` / `content_blocked`, backend does not receive the request.
3. Hits mask category (e.g. phone number) → response Part becomes `[REDACTED]`, structural fields preserved.
4. No token → `-31401` / `unauthenticated`.
5. Temporarily scale `a2a-guardrail` to 0 → request returns `-32010` (`A2A_CONTENT_SAFETY_FAIL_CLOSED=true`); recovers after restore.

Audit:

```powershell
$kc = ".tools/k3s-kubeconfig-73.yaml"
$pod = kubectl --kubeconfig $kc -n otpmask get pods -l app=a2aproxy -o jsonpath="{.items[0].metadata.name}"
kubectl --kubeconfig $kc -n otpmask logs $pod --tail=50
```

`a2aproxy` is a scratch image with no `cat`/`sh`; the audit file is in emptyDir and must be read temporarily via the node hostPath, or changed to a sidecar/persistent volume. Production recommends `policyaudit`/WORM.

## 8. Must replace before production

1. **Entry**: delete NodePort `30086`, change to ClusterIP + Higress routing; fix the `higress-gateway` hostPort collision replica.
2. **Registration snapshot**: change to control-plane signed snapshot / registry pull, do not use static ConfigMap.
3. **ACL/token**: connect to secret management and rotation; forbidden to write fixtures into the repo or long-term use of static bearer.
4. **Audit**: emptyDir JSONL → WORM/central audit, add integrity check and retention policy.
5. **Guardrail**: connect L2/ML by business tier (qwen3guard optional); this directory only verifies the L1 rules version.
6. **Image**: production Dockerfile build and scan; local scratch image has no CA bundle.
7. **Tracing**: confirm Collector → Tempo link is queryable before claiming tracing acceptance passed.
