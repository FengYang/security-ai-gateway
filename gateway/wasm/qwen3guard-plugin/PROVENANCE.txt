    工具链：Go 1.27 / GOOS=wasip1 GOARCH=wasm / -buildmode=c-shared
    必需参数：-trimpath（去绝对源码路径） + -buildvcs=false（不嵌 VCS revision/modified）
    产物：7,954,887 bytes
    sha256：f2ba8d9cc1c85327d76832780c7eae60cfe1aeecd08dc6f2cb537d1f804ba7a9

    踩坑记录（供后人省时间）：仅加 -trimpath 仍不可复现——因为在 git 工作树内构建时

    -buildvcs=false。此前一次未加这两个参数的构建产物为 7,967,896 bytes /
    sha256 1a15c4c3990f137e6d579da5b5aa9aa6a67736e312a3cffaa2a9c775a2930580，已作废。

运行前提与已知行为（完整说明见 UPSTREAM-README.txt）
---------------------------------------------------
1. 需一个 OpenAI 兼容（POST /v1/chat/completions）的 Qwen3Guard 服务；本仓库提供本地替身
   scripts/stub-qwen3guard.py 用于无模型联调（按插件解析规则返回 Safety 判定）。
2. 服务发现：dns 模式下 Envoy cluster 名为 outbound|<servicePort>||<serviceName>.dns，
   因此 serviceName 不要写 `.dns`（否则变成 `.dns.dns`）。
3. 插件 ABI：Proxy-Wasm 0.2.100（本仓库使用的 Higress 2.x 数据面满足）。
4. **fail-open**：安全服务不可用/超时/返回非 200/解析不出 Safety 标签时放行当前请求；
   与项目 fail-closed 哲学不一致，生产必须为可用率、超时与插件错误日志配置告警。
5. denyCode 语义（本机实测）：默认 200 时返回 OpenAI 兼容拒答体（内容=denyMessage）；
   设为 403 时**响应体为空**（仅状态码）。按客户端容错能力选择。
