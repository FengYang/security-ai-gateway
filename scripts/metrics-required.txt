# Metrics "all-green" checklist (Phase 1 gate #9)
#
# Format: <source> <metric> <required|conditional>
#   source   = tee | admin | plugin   (see check-metrics-green.ps1)
#   required = must exist whenever the source is reachable
#   conditional = registered only after a specific event / switch; treated as SKIP
#                 when absent (NOT a failure), because the trigger has not happened.
#
# Semantics: FAIL only when a `required` metric is missing from a reachable source.
# Rationale: plugin/tee counters are lazily defined (proxywasm.DefineCounterMetric on
# first increment; tee-infer counters likewise), so a never-triggered counter does not
# exist. Judging them as failures would make "all green" unreachable by design.
#
# NOTE: keep this file ASCII-only (PS 5.1 Get-Content reads BOM-less files as ANSI).
