## 1. 评审方法与判定标准

### 1.1 L3 标准（引自 P0 附录 F，权威口径）

- L1 概念级：不能用于开发；
- L2 设计级：状态机/流程图 ＋ 伪代码 ＋ 数据结构 ＋ 边界条件，可开始编码；
- **L3 可开发级：完整伪代码 ＋ 接口定义 ＋ 边界条件 ＋ Wasm/运行环境适配 ＋ 测试用例清单。**

门禁：开发启动前所有功能点 **≥ L2**。本轮将 L3 拆为五个可量化要素逐项评分：

| 要素 | 含义 |
|---|---|
| A 完整伪代码 | 关键流程的步骤级伪代码/代码骨架 |
| B 接口定义 | 请求/响应 schema、字段类型与约束、错误码 |
| C 边界条件 | 异常分支、失败回退、容量/长度/频率约束 |
| D 运行环境适配 | 数据面/密钥通道/部署形态/跨服务契约的适配 |
| E 测试用例清单 | 可执行的用例清单（含越权、故障注入） |

评分：具备 = 1，部分具备 = 0.5，缺失 = 0；完成度 = 得分/5。

### 1.2 Go/No-Go 判定标准

- **Go**：全部子任务 ≥ L2（无 0 分要素）；V-1～V-8 可测可证；无 P0/P1 设计级未决项；
- **No-Go**：存在 < L2 的功能点，或 P0/P1 设计问题未关闭。
