# GA-AI 网关能力补齐方案 · P0-3 —— T9 计费页面 UI 回归手册与检查表

> **性质**：T9（控制台计费中心）**生产/准生产环境 UI 回归**的可执行手册 + 逐项检查表。
> **背景**：本机无控制台运行栈（无 `mvn/java`、无真实会话/SSO），无法在开发机执行真机 UI 回归；本手册供**具备运行栈的环境**照单执行。
> **日期**：2026-10-08 ｜ **依据**：《…-T9计费页面交付与fork集成说明.md》；详设 §4.3.2/§4.3.4/§4.3.5。

---

## 1. 范围与目标

验证控制台 **计费中心** 页面（`/admin-ext/billing`）在真实栈下的：菜单/路由、三 Tab 功能、写操作与权限、i18n、审计留痕、金额域隔离、`enabled=false` 隔离。

**已由自动化覆盖（本手册不重复）**：后端契约 T-4.3-1..4、E2E-1..5（真实双服务链路）、前端构建与金额域扫描。本手册聚焦**真机浏览器 UI 层**。

## 2. 前置条件（运行栈）

| 项 | 要求 |
|---|---|
| 控制台 | 由 **fork 补丁**构建的控制台前后端（`higress-console-custom.patch` + `higress-console-billing.patch` 按序 apply 后构建，见交付说明 §3）；服务 `/api` 会话/登录/代理 |
| gateway-admin-service | 启用计费（`BILLING_ENABLED=true`），价格表可读，**G1 审计链启用**（`ADMIN_AUDIT_FILE` 配置，用于审计核对） |
| tee-infer（可选） | 需核对账单/用量趋势时提供；仅核对 UI 可暂缺 |
| 权限 | 可登录控制台；可访问「账号与角色」页（admin）以派生测试账号 |

## 3. 环境准备

1. **登录**：以 admin 账号登录控制台（`/login`）。
2. **派生只读账号（M2）**：进入「账号与角色」→ 新建账号 → 角色选 **`billing_reader`**（下拉含 `admin`/`auditor`/`billing_reader`）→ 保存；再新建一个 `auditor` 账号备用。
   - 说明：非 admin 会话的计费读权限依赖令牌内 `tenant` 声明；若签发侧未写入该声明，非 admin 读计费端点将 403（fail-closed，符合 §4.3.5）。
3. **准备测试租户**：约定专用租户（如 `ui-t1`、`ui-t2`），避免污染真实数据。

## 8. 已知边界

- 非 admin 会话读计费依赖令牌 **`tenant` 声明**；未签入前仅 admin 可读（能力受限，fail-closed）。
- 控制台**无 JS 单测运行器**，金额域以源扫描门禁（`scripts/check-billing-amount-scope.ps1`）覆盖，非浏览器快照。
- `billing_reader` 需**签发侧（控制台账号表）**派生后登录方可验证。
- 后端 `mvn compile/test` 由 `admin-portal.yml`（JDK17）在具备 Java 的 runner 执行。
