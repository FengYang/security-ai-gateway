# 报备 / 上线放行单（模板）

> 用法：每次部署、每个租户（服务）**一份**；勾选并填齐证据、经**具名签署**后方可提交备案、对外服务。
> 条件定义与操作命令见《[GA-部署指南](GA-部署指南.md)》§7（两门清单见 §7.1.3，必办明细见 §7.2，证据要求见 §7.6）。
> **本单须由部署单位具名签署；开发单位不代签、不代申报，仅提供工具、可复现证据与现场支持。无具名签署本单无效。**
